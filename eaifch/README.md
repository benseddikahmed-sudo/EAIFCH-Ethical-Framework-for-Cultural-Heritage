# EAIFCH Ontology

**Persistent Identifier:** [https://w3id.org/eaifch/](https://w3id.org/eaifch/)

**Nom complet :** Cadre éthique d'IA pour l'ontologie du patrimoine culturel

## Description
EAIFCH est un vocabulaire Linked Data qui permet d’opérationnaliser les principes **CARE** (Indigenous Data Sovereignty) sous forme de contraintes computationnelles exécutables pour l’évaluation éthique et la gouvernance des biens du patrimoine culturel numérisé.
